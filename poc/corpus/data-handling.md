# Data Handling

## Classification

| Class | Examples | Rule |
|---|---|---|
| Public | Marketing material, published docs | No restriction |
| Internal | Roadmaps, org charts, most analytics | Employees only |
| Confidential | Contracts, salary data, unreleased plans | Named individuals only |
| Restricted | Customer personal data, payment details, credentials | Explicit access grant, logged |

If you are unsure, treat data as one level more sensitive than you think it is.

## Customer personal data

Personal data — names, addresses, contact details, payment information — is Restricted.
Access requires a specific business reason and is logged and reviewed.

Never copy customer data into a personal device, a spreadsheet on your desktop, a
third-party tool, or a support ticket. Never paste it into an external service of any
kind.

## Analytics and testing

Use the anonymised datasets provided for analysis and testing. Production customer data is
not to be used to test anything, ever, including "just to check something quickly."

## Retention

Customer data is retained for the life of the account plus 7 years where legally required,
then deleted. Deletion requests are honoured within 30 days.

## If something goes wrong

Report suspected data exposure to security@ immediately. Early reporting has never
resulted in disciplinary action; concealment has.
